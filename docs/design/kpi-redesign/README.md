# KPI visual overhaul — 6 September 2026

Built-in image generation produced the two concept PNGs in this directory. They are illustrative design references, not live reporting screenshots. The implemented dashboard uses the existing application shell, Source Serif 4 headings, DM Sans values, and real server-provided KPI records. Generated names, dates, values, sidebar destinations and unsupported claims are not implementation requirements.

The user requested a complete chart-led visual overhaul within the existing system. This supersedes the earlier KPI brief's table-led composition and no-pie-chart restriction. No provider or accounting logic was changed in this redesign.

Implementation: `components/kpis-workspace.tsx` and `components/kpis-workspace.module.css`. Both views retain common date controls (7/30/90 days, All time, custom). Business reporting uses a timeline, order-share channel donut, product ranking and customer composition. Affiliate reporting uses a timeline, switchable creator rankings, positive creator-sales concentration, searchable details and mobile disclosures. Exact chart/product/channel data remains accessible. Negative rank values are labeled and do not draw positive bars.

Validation: 21 tests, typecheck, lint and production build passed. Authenticated local browser checks covered both views at desktop/mobile sizes, ranking modes, search, show-all, date changes and mobile disclosure. The independent visual review's listed fixes were scored resolved with disposition `ship`.

# Use TikTok Shop affiliate records as the affiliate KPI reporting authority

TikTok Shop affiliate KPI reporting will use TikTok Shop's seller affiliate-order and affiliate-account video analytics records as its attribution authority, joining existing imported orders only through stable provider identifiers. This deliberately avoids inferring affiliate performance from ordinary TikTok Shop orders, which would make revenue and creator attribution unreliable; TikTok Ads reporting remains out of scope until its API access is verified. The shared **All time** reporting option means all affiliate history retained by Serenity Hue from its initial 90-day provider baseline onward, not unverified historic TikTok data. Shopify, TikTok Shop, and affiliate reporting snapshots refresh together through the scheduled reconciliation every five minutes; each KPI continues to show the latest successful stored snapshot when a provider refresh fails.
